## Description

Agreed direction (2026-08-22): shared memory documents attach at initiative, project, and milestone level, inherited downward. When an agent is dispatched on a task, its context includes milestone memory layered over project memory (over initiative memory). Milestone memory holds tactical context (mid-epic decisions, gotchas); project memory holds durable context (architecture choices, conventions).

Agents write to their milestone's memory through an MCP tool; humans can edit any level in the app. When a milestone closes, a promotion step reviews what graduates to project memory — tactical notes die with the milestone, durable lessons persist.

Blocked by the planning-hierarchy epic (memory attaches to its levels).
